# De Gouden Korst – demo webshop

A small static webshop for **De Gouden Korst**, a *fictional* bakery. It is the demo deliverable
used to show [Milestone Escrow](https://github.com/jeroenzwiers/milestone-escrow) in action: a
freelancer builds this shop milestone by milestone, and an AI reviewer checks each pull request
against the agreed acceptance criteria before the escrowed payment is released.

All product illustrations are original SVG artwork made for this demo. Payments use the PayPal
sandbox; no real money is involved.
